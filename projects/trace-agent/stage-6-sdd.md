# 6단계 SDD · 작업 시퀀스

데이터 계약 v1.3, 요구사항 R03·R04·R08·R10·R11을 적용했다. 시퀀스와 사건 상세는 작업·표본·revision·epoch를 공유한다. 레인과 사건의 근거는 4단계와 같다. [기준판 구현 인계](https://github.com/0xmhha/study/blob/26508908b43b312365463749588e82eda47f29c0/projects/trace-agent/07-implementation-handoff.md)

## 표시 기준

명시적 배정에서 레인 간 위임을 읽는다. 도구 결과는 호출한 에이전트로 돌아간다. 자식의 최종 반환은 반환 근거가 별도로 필요하다. 부모가 두 반환을 받고 계속했음을 설명할 수 있을 때 JOIN과 두 JOIN_INPUT을 표시한다. 같은 스트림의 검증된 원천 순서와 명시적 선행 관계를 먼저 적용한다. 같은 시계 안에서는 사건 시각을, 별개 시계 사이에서는 안정 ID를 사용한다. 순환에 걸린 근거의 순서는 불명으로 표시한다. 시각이 없는 사건은 타임라인에 놓지 않는다.

선택한 사건의 상태는 해당 사건을 포함한 접두 구간에서 계산한다. 현재 상태, 특정 사건 당시 상태, 페이지 직전 상태는 각각 따로 조회한다. 레인을 좁히거나 페이지를 바꿔도 대기·하위 수에는 작업의 모든 관련 레인을 반영한다. 참여자 상세에는 선택 당시의 상태, 가장 최근 사건과 유효한 대기 대상이 나온다.
